# Social Media & Communication API

A scalable backend architecture for social media interactions.

## Tech Stack
- Node.js & Express
- TypeScript
- MongoDB (NoSQL)
- GraphQL
- Redis (Session/Cache)

## Core Capabilities
- Secure User Authentication (OTP & JWT)
- Post interactions (reactions, comments)
- Live notification system architecture
